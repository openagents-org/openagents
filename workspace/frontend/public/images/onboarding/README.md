# Onboarding artwork

`water-lilies.webp` is a resized reproduction of *Water Lilies* (1906), Claude Monet, Art Institute of Chicago, accession 1933.1157.

- Collection: https://www.artic.edu/artworks/16568/water-lilies
- Download: https://commons.wikimedia.org/wiki/File:Claude_Monet_-_Water_Lilies_-_1933.1157_-_Art_Institute_of_Chicago.jpg
- Public domain artwork; photographic reproduction released under CC0 1.0. See the Wikimedia file page for licensing details.
- Resized to 1800px and encoded as WebP for the onboarding preview. Served locally; no third-party image requests.
