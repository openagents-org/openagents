# [Feature] Node.js-Free OpenAgents Studio

## == Overview / Objective / Timeline

**Problem:** Users need to install Node.js and npm to run OpenAgents Studio, creating a barrier to entry.

**Goal:** Enable users to run `openagents studio -s` immediately after `pip install openagents`, just like Jupyter Notebook.

**Timeline:** 2 person-days

---

## == Functional Requirements

### 1. Pre-built Frontend
- Build React app during package release
- Bundle static files into Python package
- Serve from `src/openagents/studio/build/`

### 2. Python Static Server
- Replace Node.js dev server with Python HTTP server
- Use `aiohttp` for async support and WebSocket compatibility
- Serve static files and handle SPA routing

### 3. CLI Simplification
- Remove Node.js/npm checks from `cli.py`
- Remove npm installation logic (lines 502-762)
- Launch static server instead of Node.js

### 4. Development Mode
- Keep Node.js workflow for contributors
- Auto-detect development vs production mode
- Fall back to npm if running from source

**Add:**
```python
def launch_static_studio(port: int):
    """Serve pre-built studio from bundled assets"""
    import aiohttp.web as web

    build_path = Path(__file__).parent / "studio" / "build"

    async def serve():
        app = web.Application()
        app.router.add_static('/', build_path, show_index=True)
        runner = web.AppRunner(app)
        await runner.setup()
        site = web.TCPSite(runner, '0.0.0.0', port)
        await site.start()

    return asyncio.run(serve())
```
