# [Feature] Plugin-based Mod UI Architecture

## == Overview / Objective / Timeline

**Problem:** Mod UI components are currently scattered in `studio/src/components/`, separated from their backend code. This makes mods hard to develop, maintain, and distribute as independent plugins.

**Goal:** Enable mods to bundle their UI code alongside backend code, making each mod a self-contained plugin that can be developed and distributed independently. **No Node.js required for end users** - mod UIs pre-built at package time.

**Timeline:** 2 person-days

---

## == Functional Requirements

### 1. Colocated UI Structure
- Each mod contains its own UI code
- Location: `src/openagents/mods/core/{mod_name}/ui/`
- UI components bundled with mod backend code
- Studio dynamically discovers and loads mod UIs

### 2. Mod UI Manifest
- Each mod declares UI metadata in `mod_manifest.json`
- Manifest includes:
  - UI component entry point
  - Sidebar icon/label
  - Route path
  - Required permissions

### 3. Dynamic Mod Loading
- Studio scans installed mods at runtime
- Loads mod UI components dynamically
- Registers routes and sidebar items automatically
- Hot-reload support for development

### 4. Pre-built UI Distribution
- **Development:** Mod UIs built with Node.js/npm during development
- **Package Time:** UIs pre-built in CI/CD before PyPI release
- **Runtime:** Pre-built static files served by Python (no Node.js needed)
- **Location:** `ui/dist/` contains pre-built assets included in package

### 5. Build System
- Mods built independently during development
- CI/CD builds all mod UIs before package release
- TypeScript compilation for mod UIs
- Static files bundled and included in Python package

### Step 1: Mod Discovery & Static Serving (0.3 PD)
```python
# src/openagents/studio_integration/mod_loader.py
def discover_mods():
    """Scan mods directory and load manifests"""
    mods = []
    for mod_path in MOD_PATHS:
        manifest = load_manifest(mod_path / "mod_manifest.json")
        if manifest.get("ui", {}).get("enabled"):
            mods.append(manifest)
    return mods

# Expose mod manifests via API
@app.get("/api/mods/ui-manifests")
def get_ui_manifests():
    return discover_mods()

# Serve pre-built mod UI static files (no Node.js needed!)
@app.get("/api/mods/{mod_id}/ui/{path:path}")
def serve_mod_ui(mod_id: str, path: str):
    """Serve pre-built mod UI static files"""
    mod_path = MODS_PATH / mod_id / "ui" / "dist" / path
    if mod_path.exists() and mod_path.is_file():
        return FileResponse(mod_path)
    raise HTTPException(status_code=404)
```

### Step 2: Studio Mod Registry (0.5 PD)
```typescript
// studio/src/config/modRegistry.ts
interface ModUIConfig {
  mod_id: string;
  route: string;
  sidebar: {
    label: string;
    icon: string;
    position: number;
  };
}

// Fetch mod manifests from backend
const loadModRegistry = async (): Promise<ModUIConfig[]> => {
  const response = await fetch('/api/mods/ui-manifests');
  const manifests = await response.json();

  // Load pre-built mod UIs via script tags
  for (const manifest of manifests) {
    await loadModUI(manifest.mod_id, manifest.ui.entry);
  }

  return manifests.map(m => ({
    mod_id: m.mod_id,
    route: m.ui.route,
    sidebar: m.ui.sidebar
  }));
};

// Load pre-built mod UI (no Node.js needed!)
const loadModUI = (modId: string, entryPath: string): Promise<void> => {
  return new Promise((resolve, reject) => {
    const script = document.createElement('script');
    script.src = `/api/mods/${modId}/ui/${entryPath}`;
    script.type = 'module';
    script.onload = () => resolve();
    script.onerror = () => reject(new Error(`Failed to load ${modId}`));
    document.head.appendChild(script);
  });
};
```

### Step 3: Dynamic Route Registration (0.4 PD)
```typescript
// studio/src/App.tsx
const App = () => {
  const [modRoutes, setModRoutes] = useState<ModUIConfig[]>([]);

  useEffect(() => {
    loadModRegistry().then(setModRoutes);
  }, []);

  return (
    <Routes>
      {/* Static routes */}
      <Route path="/" element={<Home />} />

      {/* Dynamic mod routes */}
      {modRoutes.map(mod => (
        <Route
          key={mod.mod_id}
          path={mod.route}
          element={<mod.component />}
        />
      ))}
    </Routes>
  );
};
```
