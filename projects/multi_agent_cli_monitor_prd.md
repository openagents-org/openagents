# [Feature] Multi-Agent CLI Monitor with Tab Switching

## == Overview / Objective / Timeline

**Problem:** The `openagents agents start folder/` command exists with a tabbed UI (`agent_monitor.py`), but the log streaming integration is incomplete. Agents start successfully, but their logs are not captured and displayed in the UI. The monitor only shows status changes instead of actual agent output.

**Goal:** Complete the multi-agent CLI monitor feature with real-time log streaming from agent subprocesses, enabling developers to monitor multiple agents simultaneously in a single terminal with tab switching between agents.

**Current State:**
- ✅ `BulkAgentManager` discovers and starts agents from folder
- ✅ `AgentMonitorApp` (Textual UI) with tabbed interface exists
- ❌ Log capture from agent subprocesses not implemented
- ❌ Log streaming to UI not integrated
- ❌ Asyncio integration with Textual needs fixes

**Timeline:** 1 person-day

## == Functional Requirements

### 1. Real-time Log Capture

**From Agent Subprocesses:**
- Capture stdout and stderr from each agent subprocess
- Non-blocking log reading using asyncio streams
- Buffer management to prevent memory overflow (max 1000 lines per agent)
- Preserve log formatting and color codes from agent output

**Implementation:**
- Replace simple `subprocess.Popen` with asyncio subprocess
- Use `asyncio.create_subprocess_exec` with `PIPE` for stdout/stderr
- Implement async log reader that streams to shared buffer
- Thread-safe log buffer accessible by both manager and UI

### 2. UI Log Streaming Integration

**Log Display:**
- Stream captured logs to corresponding agent tabs in real-time
- Auto-scroll to latest logs (with toggle option)
- Color-coded log levels (INFO, WARN, ERROR, DEBUG)
- Timestamp each log entry
- Search/filter logs within tabs (future enhancement)

**Tab Navigation:**
- Overview tab showing all agents' status
- Individual tabs for each agent's logs
- Keyboard shortcuts:
  - `Tab` / `Shift+Tab`: Navigate between tabs
  - `q` / `Ctrl+C`: Quit and stop all agents
  - `r`: Refresh display
  - `s`: Jump to overview
  - `f`: Toggle auto-scroll
  - `c`: Clear current tab logs

### 3. Agent Status Monitoring

**Overview Tab:**
- Table with columns: Agent ID, Status, File Type, PID, Uptime, Config File
- Color-coded status indicators (● green/red/yellow/gray)
- Update frequency: 2 seconds
- Click to jump to agent's log tab (if Textual supports it)

**Status Types:**
- `starting` (yellow): Agent process launching
- `running` (green): Agent connected and active
- `error` (red): Agent crashed or failed
- `stopped` (gray): Agent terminated normally

### 4. Graceful Shutdown

**On Exit (q or Ctrl+C):**
- Display shutdown message in UI
- Terminate all agent subprocesses gracefully (SIGTERM)
- Wait up to 5 seconds for clean shutdown
- Force kill (SIGKILL) any remaining processes
- Show summary of stopped agents
- Close UI cleanly

### 5. Error Handling

**Common Failures:**
- Agent process crashes → Mark as error, show exit code in logs
- Connection failures → Display in agent's log tab
- UI crashes → Fall back to no-UI mode with basic monitoring
- Missing `textual` dependency → Show install instructions

### 1. Log Capture Architecture

```python
# In BulkAgentManager
class AgentInstance:
    process: Optional[asyncio.subprocess.Process] = None
    log_queue: asyncio.Queue[str] = None  # Shared queue for logs
    log_buffer: List[str] = []  # Last 1000 lines

async def _capture_logs(self, agent_instance: AgentInstance):
    """Async log capture from subprocess stdout/stderr."""
    if not agent_instance.process:
        return

    async def read_stream(stream, prefix=""):
        while True:
            line = await stream.readline()
            if not line:
                break

            decoded = line.decode('utf-8', errors='replace').rstrip()
            timestamp = datetime.now().strftime("%H:%M:%S")
            log_entry = f"{timestamp} {prefix}{decoded}"

            # Add to queue and buffer
            await agent_instance.log_queue.put(log_entry)
            agent_instance.log_buffer.append(log_entry)

            # Limit buffer size
            if len(agent_instance.log_buffer) > 1000:
                agent_instance.log_buffer = agent_instance.log_buffer[-1000:]

    # Read stdout and stderr concurrently
    await asyncio.gather(
        read_stream(agent_instance.process.stdout),
        read_stream(agent_instance.process.stderr, "[STDERR] "),
        return_exceptions=True
    )
```

### 2. UI Integration with Asyncio

```python
# In AgentMonitorApp
async def stream_logs_to_ui(self):
    """Background task to stream logs from queues to UI widgets."""
    while not self._shutdown:
        for agent_id, agent_instance in self.bulk_manager.agents.items():
            if agent_instance.log_queue and not agent_instance.log_queue.empty():
                try:
                    log_entry = await asyncio.wait_for(
                        agent_instance.log_queue.get(),
                        timeout=0.1
                    )

                    # Write to corresponding log widget
                    if agent_id in self.agent_logs:
                        self.agent_logs[agent_id].write_line(log_entry)

                except asyncio.TimeoutError:
                    pass

        await asyncio.sleep(0.1)  # Small delay to prevent CPU spinning
```

## == Alternative Approaches Considered

### 1. File-based Log Tailing
**Rejected:** Each agent writes to log file, UI tails files
- **Pros:** Simple, decoupled
- **Cons:** Extra I/O overhead, log rotation complexity, delayed updates

### 2. gRPC/Network Log Streaming
**Rejected:** Agents stream logs via gRPC to monitor
- **Pros:** Works for remote agents
- **Cons:** Overkill for local CLI, network overhead, requires mod changes

### 3. tmux/screen Session
**Rejected:** Start each agent in tmux pane
- **Pros:** Native terminal multiplexing
- **Cons:** External dependency, harder to control, no unified UI

**Selected: Asyncio Queue-based Streaming**
- **Pros:** Native Python, real-time, efficient, full control
- **Cons:** Requires asyncio throughout codebase
