# [功能] Admin Dashboard Onboarding 体验优化

## == 概述 / 目标 / 时间线

**问题:** 当用户首次运行 `openagents network start` 时，会看到连接视图（聊天界面），但不知道接下来该做什么。没有引导式 onboarding，没有模板选择，没有清晰的价值实现路径。

**目标:** 创建首次运行 onboarding 体验，通过 Admin Dashboard 中精美的分步向导，引导新用户从 `openagents network start` 到完整配置并运行的模板网络。

**核心成果:**
- 新用户在 60 秒内理解 OpenAgents
- 用户在 3 分钟内选择并部署模板网络
- 用户感到自信，清楚知道下一步该做什么
- 后续访问显示正常的连接视图（当前行为）

**时间线:** 5-7 人天

---

## == 用户旅程

### 当前流程（问题）

```
openagents network init my-network
        ↓
openagents network start my-network
        ↓
    Studio 打开
        ↓
  连接视图（聊天界面）
        ↓
    用户困惑："现在怎么办？"
        ↓
       😞 流失
```

### 新流程（解决方案）

```
openagents network init my-network
        ↓
openagents network start my-network
        ↓
    Studio 打开
        ↓
   ┌─────────────────────────────────────┐
   │  检测到首次运行 → 进入 ONBOARDING   │
   └─────────────────────────────────────┘
        ↓
   步骤1: 欢迎 & 介绍
        ↓
   步骤2: 选择模板
        ↓
   步骤3: 配置管理员密码
        ↓
   步骤4: 模板部署
        ↓
   步骤5: 发布网络（可选）
        ↓
   Admin Dashboard（已配置的网络）
        ↓
      😊 用户成功！

   ─────────────────────────────────────
   后续运行:
   ─────────────────────────────────────

openagents network start my-network
        ↓
    Studio 打开
        ↓
   连接视图（正常行为）
```

## == 设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 首次运行检测 | 检查网络是否有 `onboarding_completed` 标志 | 简单可靠 |
| Onboarding 位置 | Studio 中的全屏向导 | 沉浸式，无干扰 |
| 模板来源 | 内置模板 + 从 showcase 仓库获取 | 离线可用，可更新 |
| 跳过选项 | 允许跳过，但不鼓励 | 高级用户需要逃生通道 |
| 进度持久化 | 每步后保存 | 用户中断后可恢复 |

## == 技术实现

### 首次运行检测

**network.yaml 新增:**
```yaml
network:
  name: my-network
  onboarding:
    completed: false  # onboarding 后设为 true
    completed_at: null
    template_used: null
```

**逻辑:**
```python
# Studio 启动时
if not network_config.onboarding.completed:
    show_onboarding_wizard()
else:
    show_connection_view()
```

### 模板定义格式

**模板清单 (templates/news-network/manifest.yaml):**
```yaml
id: news-network
name: 新闻 & 资讯
description: 代理监控信息源，整理并广播新闻更新
icon: 📰
category: communication
setup_time: 5min

mods:
  - path: openagents.mods.workspace.messaging
  - path: openagents.mods.external.rss
    config:
      sources:
        - https://news.ycombinator.com/rss

agents:
  - id: curator
    name: Curator
    description: 发现并过滤相关新闻
    adapter: openagents.adapters.anthropic

  - id: editor
    name: Editor
    description: 总结并格式化新闻条目
    adapter: openagents.adapters.anthropic

  - id: broadcaster
    name: Broadcaster
    description: 将整理的新闻发布到频道
    adapter: openagents.adapters.anthropic

files:
  - src: templates/news-network/network.yaml
    dest: network.yaml
  - src: templates/news-network/agents/
    dest: agents/
```

### 状态管理

**Onboarding 状态 (Zustand store):**
```typescript
interface OnboardingState {
  step: 'welcome' | 'template' | 'password' | 'deploying' | 'complete';
  selectedTemplate: string | null;
  adminPassword: string | null;
  deploymentProgress: number;
  deploymentStatus: DeploymentStep[];

  setStep: (step: OnboardingState['step']) => void;
  selectTemplate: (templateId: string) => void;
  setAdminPassword: (password: string) => void;
  startDeployment: () => Promise<void>;
  skipOnboarding: () => void;
}
```

### API 端点

| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/templates` | GET | 列出可用模板 |
| `/api/templates/{id}` | GET | 获取模板详情 |
| `/api/onboarding/deploy` | POST | 部署选定模板 |
| `/api/onboarding/complete` | POST | 标记 onboarding 完成 |
| `/api/onboarding/skip` | POST | 跳过 onboarding |
| `/api/admin/password` | POST | 设置管理员密码 |
| `/api/network/publish` | POST | 发布网络到 showcase |
