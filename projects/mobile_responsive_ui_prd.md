# [Feature] Mobile Responsive UI

## == Overview / Objective / Timeline

**Problem:** The OpenAgents Studio is currently designed primarily for desktop browsers. Users accessing Studio from mobile phones or tablets experience:
- Cramped navigation sidebars that overlap content
- Text and buttons too small to tap accurately
- Horizontal scrolling required to view content
- Chat input difficult to use on mobile keyboards
- Agent cards and dashboards not optimized for smaller screens
- No touch-friendly interactions (swipe, pull-to-refresh)

**Goal:** Optimize OpenAgents Studio for mobile (320px-768px) and tablet (768px-1024px) devices, providing a first-class experience for users who want to monitor and interact with their agent networks on the go.

**Target Platforms:**
- iOS Safari (iPhone, iPad)
- Android Chrome (phones, tablets)
- Mobile Firefox
- PWA installation support

**Key Decisions:**

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Approach | Responsive (not separate app) | Single codebase, consistent features |
| CSS Strategy | Mobile-first with breakpoints | Industry standard, better performance |
| Navigation | Bottom nav (mobile), sidebar (tablet+) | Thumb-friendly on phones |
| Touch Gestures | Swipe for navigation, pull-to-refresh | Native mobile feel |

**Notes**

- 测试需要覆盖默认network中的所有插件 包括 readme， messaging, project, feed, forum, wiki, artifact, agentworld. 其中 readme, messaging和project需要重点测试。
- 可使用lambdatest进行测试，也可以使用本地设备进行测试。
- 设备优先级仍然为 desktop > mobile.

**Timeline:** 3-4 PD

## == Functional Requirements

### 1. Responsive Layout System

**Breakpoints:**
```css
/* Mobile phones */
@media (max-width: 767px) { ... }

/* Tablets */
@media (min-width: 768px) and (max-width: 1023px) { ... }

/* Desktop (existing) */

```

**Layout Changes by Breakpoint:**

| Component | Mobile (<768px) | Tablet (768-1023px) | Desktop (1024px+) |
|-----------|----------------|---------------------|-------------------|
| Navigation | Bottom tab bar | Collapsible sidebar | Full sidebar |
| Sidebar | Hidden (overlay) | Collapsed icons | Full with label-s |
| Content Area | Full width | Full width | With sidebar |
| Agent List | Stacked cards | 2-column grid | 3-column grid |
| Chat | Full screen | Split view option | Split view |
| Modals | Full screen | Centered (80%) | Centered (60%) |

### 2. Navigation Redesign

**Mobile Bottom Navigation:**
- Fixed bottom bar with 5 main tabs: Home, Chat, Agents, Network, More
- "More" opens drawer with secondary navigation
- Active state with icon + label, inactive shows icon only
- Safe area padding for notched devices (iPhone X+)

**Tablet Collapsible Sidebar:**
- Icons only by default (48px width)
- Expand on hover or tap (240px width)
- Persist expanded state in user preferences

**Touch Gestures:**
- Swipe right from edge: Open sidebar/navigation
- Swipe left: Go back (where applicable)
- Swipe down: Pull-to-refresh on lists
- Long press: Context menu (alternative to right-click)

### 3. Component Responsiveness

**Chat/Messaging:**
- Full-screen chat view on mobile
- Floating action button for new message
- Swipe left on message for quick actions (reply, react)
- Auto-resize input that expands with content
- Keyboard-aware layout (input stays above keyboard)
- Voice input button for mobile

**Agent Cards:**
- Stack vertically on mobile (1 column)
- Larger touch targets (min 44x44px)
- Swipe actions: left for stop, right for details
- Collapsible details section

**Network Dashboard:**
- Scrollable horizontal metrics on mobile
- Stacked chart layouts
- Touch-friendly chart interactions
- Simplified topology view for mobile

**Wiki/Documents:**
- Reader mode toggle for focused reading
- Simplified toolbar on mobile (expandable)
- Touch-friendly text selection
- Floating save button

**Forms & Inputs:**
- Full-width inputs on mobile
- Larger input fields (min 48px height)
- Native date/time pickers on mobile
- Dropdown alternatives (bottom sheets)

### 4. Touch Optimization

**Touch Targets:**
- Minimum touch target: 44x44px (Apple HIG)
- Adequate spacing between targets: 8px minimum
- Visual feedback on touch (ripple/highlight)

**Gestures:**

| Gesture | Action |
|---------|--------|
| Tap | Primary action |
| Long press | Context menu |
| Swipe left | Delete/secondary action |
| Swipe right | Primary action (mark read, etc.) |
| Pull down | Refresh |
| Pinch | Zoom (on topology view, charts) |

### 5. Performance Optimization

**Mobile-Specific:**
- Lazy load off-screen content
- Reduce animation complexity on mobile
- Optimize images (WebP, responsive sizes)
- Minimize JavaScript bundle for mobile
- Use CSS containment for complex layouts

**Metrics Targets:**

| Metric | Target |
|--------|--------|
| First Contentful Paint | < 1.5s |
| Time to Interactive | < 3s |
| Largest Contentful Paint | < 2.5s |
| Cumulative Layout Shift | < 0.1 |

### 6. PWA Support (Optional Enhancement)

**Progressive Web App Features:**
- Add to Home Screen prompt
- App-like splash screen
- Standalone display mode
- Theme color matching

**useMediaQuery.ts:**
```tsx
export function useMediaQuery(query: string): boolean {
  const [matches, setMatches] = useState(false);

  useEffect(() => {
    const media = window.matchMedia(query);
    setMatches(media.matches);

    const listener = (e: MediaQueryListEvent) => setMatches(e.matches);
    media.addEventListener('change', listener);
    return () => media.removeEventListener('change', listener);
  }, [query]);

  return matches;
}

export const useIsMobile = () => useMediaQuery('(max-width: 767px)');
export const useIsTablet = () => useMediaQuery('(min-width: 768px) and (max-width: 1023px)');
export const useIsDesktop = () => useMediaQuery('(min-width: 1024px)');
```

**SwipeableCard.tsx:**
```tsx
interface SwipeableCardProps {
  children: React.ReactNode;
  onSwipeLeft?: () => void;
  onSwipeRight?: () => void;
  leftAction?: React.ReactNode;
  rightAction?: React.ReactNode;
}

export function SwipeableCard({
  children,
  onSwipeLeft,
  onSwipeRight,
  leftAction,
  rightAction,
}: SwipeableCardProps) {
  const [offset, setOffset] = useState(0);
  const startX = useRef(0);

  const handleTouchStart = (e: TouchEvent) => {
    startX.current = e.touches[0].clientX;
  };

  const handleTouchMove = (e: TouchEvent) => {
    const diff = e.touches[0].clientX - startX.current;
    setOffset(Math.max(-100, Math.min(100, diff)));
  };

  const handleTouchEnd = () => {
    if (offset > 50 && onSwipeRight) onSwipeRight();
    if (offset < -50 && onSwipeLeft) onSwipeLeft();
    setOffset(0);
  };

  return (
    <div className="relative overflow-hidden">
      {leftAction && (
        <div className="absolute left-0 top-0 bottom-0 w-24 bg-red-500">
          {leftAction}
        </div>
      )}
      {rightAction && (
        <div className="absolute right-0 top-0 bottom-0 w-24 bg-green-500">
          {rightAction}
        </div>
      )}
      <div
        className="relative bg-background transition-transform"
        style={{ transform: `translateX(${offset}px)` }}
        onTouchStart={handleTouchStart}
        onTouchMove={handleTouchMove}
        onTouchEnd={handleTouchEnd}
      >
        {children}
      </div>
    </div>
  );
}
```

interface BottomSheetProps {

export function BottomSheet({
  isOpen,
  onClose,
  title,
  children,
  snapPoints = [0.5, 0.9],
}: BottomSheetProps) {
  const [height, setHeight] = useState(snapPoints[0]);

  if (!isOpen) return null;

  return (
    <>
      <div className="fixed inset-0 bg-black/50 z-40" onClick={onClose} />
      <div
        className="fixed bottom-0 left-0 right-0 bg-background rounded-t-2xl z-50"
        style={{ height: `${height * 100}vh` }}
      >
        <div className="flex justify-center py-3">

        </div>
        {title && (
          <div className="px-4 pb-2 border-b">

          </div>
        )}
        <div className="overflow-y-auto px-4 py-2">
          {children}
        </div>
      </div>
    </>
  );
}

**PullToRefresh.tsx:**
```tsx
interface PullToRefreshProps {
  onRefresh: () => Promise<void>;
  children: React.ReactNode;
}

export function PullToRefresh({ onRefresh, children }: PullToRefreshProps) {
  const [pullDistance, setPullDistance] = useState(0);
  const [isRefreshing, setIsRefreshing] = useState(false);
  const startY = useRef(0);
  const THRESHOLD = 80;

  const handleTouchEnd = async () => {
    if (pullDistance > THRESHOLD && !isRefreshing) {
      setIsRefreshing(true);
      await onRefresh();
      setIsRefreshing(false);
    }
    setPullDistance(0);
  };

  return (
    <div className="overflow-y-auto h-full">
      <div
        className="flex justify-center items-center transition-all"
        style={{ height: pullDistance }}
      >
        {isRefreshing ? <Spinner /> : <ArrowDown />}
      </div>
      {children}
    </div>
  );
}
```
