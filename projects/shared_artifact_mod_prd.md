# [Feature] Shared Artifact Mod

## == Overview / Objective / Timeline

**Problem:** Shared cache stores data temporarily in memory. Agents need persistent file storage in the workspace for documents, images, and other artifacts.

**Goal:** Create a mod like shared_cache but for persistent files stored in `{workspace}/shared_artifacts/`.

---

## == Functional Requirements

### 1. File-based Storage
- Store artifacts as actual files in workspace
- Location: `{workspace}/artifacts/`
- Metadata: `{workspace}/artifacts/.metadata.json`
- Each artifact stored by its artifact_id
- Optional name field (can be natural language, e.g. "Monthly Sales Report")

### 2. CRUD Operations
- Create: Save file with content
- Get: Retrieve file content + metadata
- Update: Modify file content
- Delete: Remove file
- List: Get all artifacts (optional filter)

### 3. Access Control
- Same as shared_cache: agent group-based permissions
- Empty groups = public access

### 4. File Support
- Text files (JSON, MD, TXT, etc.)
- Binary files (images, PDFs) # based64 encoding when returned as a response

### 5. Event System

**Operational Events:**

```python

```

```python
      "file_size": 18,
      "created_by": "agent_alice",

      "updated_at": 1699564800
    }
```


**Notification Events:**
- `shared_artifact.notification.created` - Broadcast when artifact is created
- `shared_artifact.notification.updated` - Broadcast when artifact is updated
- `shared_artifact.notification.deleted` - Broadcast when artifact is deleted

## == Reference: Implementation Plan generated by Claude

Important: this section is only for reference.

### Step 1: Copy & Modify Shared Cache
- Copy `shared_cache/mod.py` → `shared_artifact/mod.py`
- Replace in-memory dict with file operations
- Add file path handling

### Step 2: Storage Structure
```python
# Metadata index: {workspace}/artifacts/.metadata.json
{
  "artifact-id": {
    "artifact_id": "uuid",
    "name": "analysis.json",  # Optional
    "file_path": "{workspace}/artifacts/artifact-id",
    "mime_type": "application/json",
    "file_size": 1024,
    "allowed_agent_groups": ["analysts"],
    "created_by": "agent_alice",
    "created_at": 1699564800,
    "updated_at": 1699651200
  }
}

# Actual files: {workspace}/artifacts/{artifact-id}
# Files stored by artifact_id, not by name
```

### Step 3: Key Changes from Shared Cache

| Shared Cache | Shared Artifact |
|-------------|-----------------|
| `self.cache_entries: Dict` | `self.artifact_entries: Dict` + files |
| Value in memory | Value on disk |
| Save to `cache_data.json` | Save to `.metadata/artifacts.json` + files |
| `value` field | Read/write file at `file_path` |

## == Key Differences from Shared Cache

✅ **Persistent** - Files survive restarts
✅ **File-based** - Actual files in workspace, not JSON values
✅ **Binary support** - Images, PDFs via base64
✅ **Path organization** - Subdirectories like `reports/`, `images/`
✅ **File metadata** - Size, MIME type tracked automatically
